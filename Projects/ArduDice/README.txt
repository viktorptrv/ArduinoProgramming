Visual G-Force direction with Arduino Uno and MPU6050, visualised by using WS2812.

Arduino code + electrical schematic + Fusion360 file can be found here: 

You can find the arduino code here: https://github.com/viktorptrv/ArduinoProgramming/tree/main/Projects/ArduDice

 

For the whole project you need:

    Arduino UNO (doesn't matter as long as it's Uno/Minima size).
    MPU6050
    WS2812 8x8 
    9V Battery
    Double sided tape
    4p x m3 x 8mm screws - used to screw together the walls
    2p x m3 x 6mm screws - used to screw down the arduino board
    8p x m3 x 16mm screws - used to screw together top and bottom to the walls.
    4p x m2.5 x 6mm screws - used to screw down the WS2812 board
    Screwdriver

    a Way to make your own cables( way better than using standard arduino cables)
